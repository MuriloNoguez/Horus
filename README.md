# Horus - Sistema de Publicações Esportivas

Este projeto foi desenvolvido no segundo semestre do curso de Análise e Desenvolvimento de Sistemas (ADS), na disciplina de Programação Web, por:

- Murilo Noguêz
- Silvio Castilhos
- Ian Porto

## Sobre o Projeto

O sistema permite que usuários cadastrem, visualizem e participem de publicações esportivas. Os dados de usuários e posts são armazenados de forma persistente no navegador, utilizando o localStorage.

## Tecnologias Utilizadas

- React
- Vite
- Tailwind CSS
- React Router DOM
- react-hook-form
- LocalStorage 
- ESLint

## Observações

- O projeto utiliza Hot Module Replacement (HMR) para desenvolvimento rápido.
- Não há backend: toda a lógica e persistência são feitas no fronEnd.
